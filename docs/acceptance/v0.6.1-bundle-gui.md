## GUI execution

The daily official application was observed displaying Insights 0.6.1 with its existing disabled setting. Functional tests used a separate synthetic home and Electron user-data directory, with Insights selected only in that test profile. The supported welcome flow allowed configuration to be deferred without entering or copying credentials.

Two populated synthetic sessions were written through the official persistence service before launching the GUI: one target project and one unrelated project. In the actual `dsh-app://app/` window, the tester selected the synthetic working directory through the native folder picker, observed `/session-insights` completion, pasted the full deterministic command and clicked Send. Chinese and English commands produced nonempty reports without a model acceptance run. Each report contained the target fixture plus the current GUI command session in the same project; the unrelated fixture was excluded.

Report viewing is separate from Electron command dispatch. The plugin returns a file path and a manual viewing hint; it does not spawn a browser or embed a report viewer. The English report generated by the GUI was rendered through a temporary loopback preview serving only that synthetic run directory. Selecting Aborted changed the session count from two to one; Reset restored two. A persistent result card in the new-chat page and direct `file://` rendering are not claimed by this check.

The isolated application and preview server were stopped afterward. On macOS, the daily Desktop returned to its original running state and page, with Insights still disabled; Web and Headless remained stopped. Windows returned to its newly captured all-stopped baseline; its QA and temporary preview processes also stopped.
