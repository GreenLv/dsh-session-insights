# v0.3.0 release acceptance record

Status: released as `v0.3.0` from commit `d6065402dcae195eba6f6cd8cdd453bc8129b9f1` on 2026-08-25. This change set is presentation-facing (dashboard layout, usage cards, unit/legend fixes) plus parser-level per-session counters; it is platform-neutral. The Windows-native pass is recorded separately in [`windows-v0.3.0.md`](windows-v0.3.0.md); it closed the three real-model gates and added rendered-English-DOM evidence, while leaving the interactive `/session-insights` slash dispatch unverified (see the boundaries below).

## Scope

- Dashboard layout overhaul: unified card system, aligned filter toolbar, document-order scroll-aware TOC chip navigation, KPI reorder, active-time hours unit, `会话明细` (Session details) rename, color accents.
- Usage section cards: Skill usage and plugin/MCP usage, alongside session types, tools, file types, and active hours.
- Deterministic analyzers now record per-session `skill_calls` and export `skill_usage` / `plugin_usage` aggregates (parser contract DSH `0.2.2` / sibling `6.0.4`).
- README 'What you get' table and light-theme screenshots refreshed.
