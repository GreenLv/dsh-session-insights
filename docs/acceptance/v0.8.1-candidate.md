## 依赖与明确风险决定

| 范围 | 结果 |
| --- | --- |
| root production / full | clean，原始 JSON 和退出码分别保留 |
| rc.2 runtime | clean |
| rc.2 完整 host | 原始扫描退出 1；10 项直接公告；初次 75、独立重扫 78 个受影响包条目，直接公告集合相同 |
| Python | 单独审计，结果与 Node 分开记录 |

undici 8.11.2 有 8 项公告（4 high、4 moderate），MCP client 2.2.0 和嵌套 fflate 0.8.2 各有 1 项 moderate。包条目数与直接漏洞数含义不同。宿主对这些版本的精确 pin 使 DSI 自己的依赖范围无法解除它们。

维护者于 2026-11-13 明确接受 0.8.1、精确 rc.2 host manifest/lock 及这 10 项公告和已审查报告范围内的风险。`config/host-dependency-risk.json` 绑定该决定：host 原始退出码仍为 1，策略结果为 `accepted_known_risk`，汇总为 `passed_with_known_host_risk`，不能写成 clean。root/runtime/Python 不获得该例外；输入变化、新公告、未经审查的报告、扫描或采集失败仍拒绝。旧 0.8.0 Zod 例外保持历史身份。详见[安全说明](../../SECURITY.md#known-upstream-dependency-gap)。
