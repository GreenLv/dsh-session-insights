### 范围和限制

- macOS Web 场景的私有 overlay 关闭 HMR watcher 和标题模型；Windows 保持默认 HMR。macOS 模型场景使用官方 base profile，只读复用现有宿主认证，避免 Web 认证向日常凭据文件写入；完整 Web 验收另行记录。
- 取消在操作尚未结束时触发。macOS 观察之后 500 ms、Windows 观察之后 500/1000 ms 内没有晚到产物；这不定位 worker 阶段，也不提供无限时间保证。
- Windows 未重复模型流程；模型协议由 macOS 的同包实际模型场景覆盖。Linux 有 CI，没有原生宿主验收。
- 所有场景使用合成会话。报告运行、安装及活跃资源已清理；Windows 的合成源数据和执行证据保留在私有证据目录。
- 自动化浏览器禁止 `file://`。中英文报告的直接离线打开及复制后粘贴已由用户确认；HTTP 自动化验收和人工离线验收分别记录。

## English

This patch targets only DSH `0.2.0-rc.1`. Start a new analysis run after upgrading; existing reports remain. Update a separately installed Python CLI/Skill independently.

The JSON receipts and canonical tarball are available in the linked GitHub Release assets. The commit and canonical tarball above are identical across consumers. All 13 CI jobs passed. Both native platforms verified official installation, real JSONL persistence and cold reads after reboot, actual Agent commands, populated bilingual reports, project isolation, cancellation/rerun and cleanup. Each selected recovery fixture reports one confirmed failure, one unknown outcome, one call without a start record, and zero confirmed retries.

On macOS, one nonempty task family completed the actual model batch/aggregate/finalize workflow with status `complete`. The generated recommendations treat recovery as uncertainty and ask for external-state verification before retrying. Windows did not repeat the model protocol. Linux is covered by CI only.

macOS disabled the HMR watcher and title model in its private Web overlay. Its model scenario used an official base profile with read-only access to existing host authentication; the full Web scenario is separate. Windows retained default HMR. Cancellation observations cover 500 ms on macOS and 500/1000 ms on Windows, without claiming a particular worker phase or indefinite quiescence. Synthetic report runs, installations and live resources were cleaned; private Windows synthetic source evidence is retained.

Both locale pages and their affected interactions passed over loopback HTTP, and exported JSON/Markdown files were independently read back. Automated `file://` access is prohibited; direct offline opening and pasted copy content were subsequently confirmed by the user. Public documents and annexes use anonymous evidence identifiers and contain no local-user paths, thread identifiers or private-repository references.
