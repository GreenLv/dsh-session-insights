# 0.6.0 release acceptance

Session Insights 0.6.0 is published on [npm](https://www.npmjs.com/package/dsh-session-insights/v/0.6.0) and [GitHub Releases](https://github.com/GreenLv/dsh-session-insights/releases/tag/v0.6.0). It adds background-job and working-directory analysis for DSH 0.2.1-rc.2. The same accepted tarball was used for both channels.

Use DSH `>=0.2.1-rc.2` and start a new analysis run after upgrading. Existing reports remain on disk. Separately installed Python CLI and Skill copies need their own update; installing the Bundle does not update them.

## Independent review and native acceptance

## Limits of this evidence

- Windows Desktop command autocomplete was not observed. It remains an optional `not_run` check; actual command dispatch was exercised through the official Desktop profile separately.
- Later DSH versions admitted by the declared range have not thereby been tested. Synthetic fixtures and bounded model runs do not establish correctness for every real session.
- Performance and memory samples describe their measured workloads, not a guaranteed latency, host RSS ceiling or billing amount.
- Publication, disk installation, configuration and loaded behavior are separate results. Local consumer updates and final host state are recorded by their owning deployment workflow.

This record was added after publication. It does not alter the tagged source or the released tarball.
