Status: released as `v0.2.0` from commit `7e9f1e3e50cdf464de59edf3a81cebc7f06c2ed8` on 2026-08-22. Its runtime remains unchanged from acceptance basis `11d6fe43a87398a2403f6533b4c06d2d89ad95a3`, which passed focused Windows revalidation; the later release commit contains registry-facing README and release-document changes. The exact npm artifact, remote tag, GitHub Release assets, and release-commit CI were independently read back as recorded below.

## Scope

- Native DSH Bundle with `/session-insights` and six model-facing workflow tools.
- Trusted `sessionQuery` ingestion over a versioned JSONL stdin bridge.
- Existing deterministic analyzer, semantic validation/fallback pipeline, file-log CLI, and Skill compatibility.
- `zh-CN` and `en` report locale plus language-specific semantic prompt contracts.

The first sandboxed Web startup failed at `listen EPERM` on `127.0.0.1`. Repeating the same isolated profile startup in system context succeeded and printed a live local URL; the failure is classified as a command-sandbox socket restriction, not a Bundle load failure.

The first independent macOS DSH review found unsafe ordered substring replacement in the English Dashboard, incomplete resume/cancellation/repair-to-fallback coverage, and an unsupported follow-up `ContextForm`. The second review confirmed those repairs, then reproduced a false run-root rejection when a canonicalized `/private/var` root was compared with a not-yet-created `/var` child, and found three framework-owned Chinese strings in a semantic English report. The candidate now canonicalizes through the deepest existing ancestor and localizes those semantic-finalization strings. A third independent macOS review closed both findings: two semantic prepares and two deterministic commands succeeded under a `/var`-aliased DSH home, a complete English semantic report rendered with zero CJK characters outside scripts, all 10 Node and 35 Python tests passed, and the audited npm payload contained the intended 17 files. No remaining macOS release blocker was found.

Independent Windows acceptance first bound base commit `ada5f10`, passed the native Bundle lifecycle, and exposed validator-only aggregate enums that caused the real-model English run to fall back. Commit `1fe5bc4` disclosed those enums, added contract-parity coverage, and made POSIX-rooted Windows project filters fail with an actionable native-path error. Focused revalidation on `11d6fe4` closed both findings: native project filtering behaved as documented, and real-model `en` plus `zh-CN` workflows completed without fallback. The Windows run did not natively invoke deterministic slash dispatch or browser DOM localization; macOS browser evidence and Node integration coverage remain the evidence for those surfaces.
