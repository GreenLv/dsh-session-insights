# DSH Session Insights 0.5.0

## 中文

本版适配 DeepSeek Harness `0.1.7-rc.2`，把新会话格式、程序化工具调用和审批结果纳入复盘。

### 变化

- Bundle 和可选 Python CLI 只读取 V4 会话。旧原始日志需先通过上游 DSH 迁移；升级后请新建分析运行，已有报告保留。
- 记录 PTC 内层工具执行，并分别展示内外层失败。权限拒绝不再误计为验证命令执行失败，工具注册通知和定时注入不计作人工请求。
- 使用官方消息构造与可取消的会话观察接口；读取完成后释放观察资源，卸载插件时等待自身任务结束。

### 升级

只支持 DSH `0.1.7-rc.2`，Node.js 要求为 `^22.19.0 || >=24.0.0`。Bundle 无需 Python；单独安装的 Python CLI/Skill 需另行更新至 0.5.0。

验收范围及尚未覆盖的平台、模型和页面交互见[验收记录](https://github.com/GreenLv/dsh-session-insights/blob/v0.5.0/docs/acceptance/v0.5.0-rc2-candidate.md)。

[完整更新日志](https://github.com/GreenLv/dsh-session-insights/blob/v0.5.0/CHANGELOG.zh-CN.md) · [安装与使用](https://github.com/GreenLv/dsh-session-insights/blob/v0.5.0/README.zh-CN.md)

## English

This version adapts session retrospectives to DeepSeek Harness `0.1.7-rc.2`, including its current session format, programmatic tool calls and approval outcomes.

### Changes

- Read V4 sessions in the Bundle and optional Python CLI. Migrate older raw logs through upstream DSH and start a new analysis run after upgrading. Existing reports are retained.
- Include PTC inner executions and show inner and outer failures separately. Permission denials do not count as failed verification commands; tool-registration notices and scheduled injections do not count as human requests.
- Use the official message helper and cancellable session observations. Release observations after reading and wait for owned tasks when the plugin unloads.

### Upgrade

DSH `0.1.7-rc.2` is the only supported host version. Node.js must satisfy `^22.19.0 || >=24.0.0`. The Bundle needs no Python; update a separately installed Python CLI/Skill to 0.5.0 independently.

See the [acceptance record](https://github.com/GreenLv/dsh-session-insights/blob/v0.5.0/docs/acceptance/v0.5.0-rc2-candidate.md) for the tested scope and remaining platform, model and browser-interaction coverage.
