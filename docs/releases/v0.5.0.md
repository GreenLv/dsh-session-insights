# DSH Session Insights 0.5.0

## 中文

本版适配 DeepSeek Harness `0.1.7-rc.2`，把新会话格式、程序化工具调用和审批结果纳入复盘。

### 变化

- Bundle 和可选 Python CLI 只读取 V4 会话。旧原始日志需先通过上游 DSH 迁移；升级后请新建分析运行，已有报告保留。
- 记录 PTC 内层工具执行，并分别展示内外层失败。权限拒绝不再误计为验证命令执行失败，工具注册通知和定时注入不计作人工请求。
- 使用官方消息构造与可取消的会话观察接口；读取完成后释放观察资源，卸载插件时等待自身任务结束。

### 升级

只支持 DSH `0.1.7-rc.2`，Node.js 要求为 `^22.19.0 || >=24.0.0`。Bundle 无需 Python；单独安装的 Python CLI/Skill 需另行更新至 0.5.0。

70 项 Node、70 项 Python 测试及 13 个 CI 任务通过；同一安装包已在 macOS rc.2 宿主完成非空真实模型语义流程和 notice 持久化读回。Windows rc.2 隔离宿主已通过安装、注册、中文空格路径筛选、非空确定性报告及取消后重跑检查；中英文离线报告的显示、筛选重置、导出和控制台检查由维护者人工验收通过。Windows 未重复模型语义测试；活跃 Agent 自动工具增删和完整进程重启恢复仍未原生验证。最终验收结果见随 Release 附带的 `release-acceptance.md`；[源码验收记录](https://github.com/GreenLv/dsh-session-insights/blob/v0.5.0/docs/acceptance/v0.5.0-rc2-candidate.md)保留冻结候选时的状态。

## English

This version adapts session retrospectives to DeepSeek Harness `0.1.7-rc.2`, including its current session format, programmatic tool calls and approval outcomes.

### Changes

- Read V4 sessions in the Bundle and optional Python CLI. Migrate older raw logs through upstream DSH and start a new analysis run after upgrading. Existing reports are retained.
- Include PTC inner executions and show inner and outer failures separately. Permission denials do not count as failed verification commands; tool-registration notices and scheduled injections do not count as human requests.
- Use the official message helper and cancellable session observations. Release observations after reading and wait for owned tasks when the plugin unloads.

### Upgrade

DSH `0.1.7-rc.2` is the only supported host version. Node.js must satisfy `^22.19.0 || >=24.0.0`. The Bundle needs no Python; update a separately installed Python CLI/Skill to 0.5.0 independently.

All 70 Node tests, 70 Python tests and 13 CI jobs passed. The same tarball completed a nonempty real-model semantic workflow and persisted-notice readback in the macOS rc.2 host. An isolated Windows rc.2 host passed installation, registration, Unicode-and-space path filtering, nonempty deterministic reporting and cancellation followed by a successful rerun. The maintainer manually verified display, filter/reset, exports and browser-console behavior in both offline report languages. Windows model semantics were not retested; active-Agent automatic tool updates and recovery after a full process restart were not tested natively. See the attached `release-acceptance.md` for final acceptance. The [source acceptance record](https://github.com/GreenLv/dsh-session-insights/blob/v0.5.0/docs/acceptance/v0.5.0-rc2-candidate.md) preserves the earlier candidate-freeze status.
