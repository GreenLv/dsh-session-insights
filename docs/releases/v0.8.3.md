# DSH Session Insights 0.8.3

## English

DSI 0.8.3 targets DeepSeek Harness `0.2.2-rc.5` and requires DSH `>=0.2.2-rc.5`. The DSH compatibility check admits later hosts under the declared range. Each later host requires verification of its interfaces and package resolution. The Bundle requires Node.js `>=24.9.0` and Cordis `~4.1.0`. The standalone CLI and Skill require Python `>=3.11`.

Only a turn ending explicitly marked `completed` is counted as complete. Blocked, output-token-limited and unknown endings stay incomplete. Closing an inherited fork does not establish completion. Search auxiliary requests do not add tool calls or tokens. Attempts without a visible response that contain usage samples are counted separately. Sample usage is excluded from token totals.

The analysis identity changes to `v4-dsh022rc5.1`. Finish an existing semantic run with its original version or start again after upgrading. Existing reports remain readable, and old deterministic caches are rebuilt. The standalone Python CLI and Skill use their own managed installer.

On 2026-11-20 the maintainer accepted ten direct advisories for the exact 0.8.3 and rc.5 host inputs. Four are high and six moderate, across 75 or 78 affected package entries in the two reviewed reports. The three-entry difference is indirect propagation of the same advisory. The raw host audit retains exit 1 and is classified as `accepted_known_risk`. Changed inputs, new findings and scanner failures require reassessment. See the [security policy](https://github.com/GreenLv/dsh-session-insights/blob/v0.8.3/SECURITY.md#known-upstream-dependency-gap).

For DSH Web, install with `dsh plugin --profile web add dsh-session-insights@0.8.3`. Use the official application's plugin controls for Desktop.

## 简体中文

DSI 0.8.3 适配 DeepSeek Harness `0.2.2-rc.5`，要求 DSH `>=0.2.2-rc.5`。DSH 兼容性检查按声明范围允许后续版本准入，实际版本需单独验证接口和包解析。Bundle 要求 Node.js `>=24.9.0` 和 Cordis `~4.1.0`。独立 CLI 和 Skill 要求 Python `>=3.11`。

只有明确标为 `completed` 的轮次计为完成。阻塞、输出 token 达到上限及未知结束原因保持为未完成。继承会话的 fork 收尾不代表用户任务完成。搜索辅助请求不会重复计入工具调用或 token 总量，单独统计带用量样本但未产出回复的尝试次数，样本用量不计入 token 总量。

分析身份更新为 `v4-dsh022rc5.1`。请用原版本完成正在进行的语义分析，或升级后重新开始。既有报告仍可打开，旧确定性缓存按需重建。单独安装的 Python CLI 和 Skill 使用各自的受管安装入口。

维护者于 2026-11-20 接受精确 0.8.3 与 rc.5 宿主输入中的十项直接公告，其中四项高危、六项中危，两份已审报告分别涉及 75 或 78 个受影响包条目，三项差异是同一公告的间接传播。宿主扫描保留原始退出码 1，结果记为 `accepted_known_risk`。输入变化、新发现和扫描故障需要重新评估。详见[安全说明](https://github.com/GreenLv/dsh-session-insights/blob/v0.8.3/SECURITY.md#known-upstream-dependency-gap)。

Web 可运行 `dsh plugin --profile web add dsh-session-insights@0.8.3`。Desktop 使用官方应用内的插件管理入口。
