# DSH Session Insights 0.8.0

## English

0.8.0 supports DeepSeek Harness (DSH) `0.2.2-rc.1` and later. Upgrade DSH before installing if you are on an older host. The Node.js requirement is `>=24.9.0`, and the Cordis peer range is `~4.1.0`.

### What changed

- The report now counts caller-cancelled tool calls separately from failures, approval rejections, and unknown outcomes. This includes `run_code` and its nested tool calls. If a call had already started, its side effects may persist.
- Cancellation evidence retains its turn and call identity in inherited sessions. Separate cancellations remain separately addressable when a model submits evidence for a report.
- The JavaScript and Python analyzers use the new `v4-dsh022rc1.1` input identity. Finish an existing semantic run with the version that created it, or start a new run with 0.8.0. Existing runs and historical V4 session logs remain available. The CLI recomputes deterministic reports when it encounters older cache entries.

### Install and verify

Use `dsh plugin --profile web add dsh-session-insights@0.8.0` for Web, or choose the profile you use. Update a standalone Python CLI or Skill separately through its managed installer.

GitHub Actions checked the candidate on Linux, macOS and Windows, including the official rc.1 session and executor contracts. The same package was installed and verified in isolated macOS and Windows profiles. On both systems, a live model completed a semantic report from synthetic sessions, and the official Desktop window ran the deterministic report command. [CI run](https://github.com/GreenLv/dsh-session-insights/actions/runs/42379286996)

The npm tarball has 29 files. Its source commit is `ae4ecb39e8a609a90bf1ead03e288e9a5fa1de45` and its SHA-256 is `92cfbc43570c055c211e0e6d2a9a33775aedb4e88a92e893a48938f165eed625`.

### Known upstream dependency gap

DSH rc.1 still pins vulnerable copies of `zod@4.4.3` in `dsh-commands`, `dsh-llm`, and `dsh-agent`. The CI production and full dependency scans each reported 18 affected package entries under the same advisory. The maintainer accepted the known risk for the reviewed 0.8.0 dependency inputs on 2026-11-06. Changes to those inputs or new advisories require review. ## 简体中文

0.8.0 支持 DeepSeek Harness（DSH）`0.2.2-rc.1` 及更高版本。旧宿主需要先升级 DSH，再安装插件。Node.js 要求为 `>=24.9.0`，Cordis 对等依赖范围为 `~4.1.0`。

### 主要变化

- 报告单独统计调用者取消的工具调用，并区分执行失败、审批拒绝和结果未知。这也涵盖 `run_code` 和它发起的子调用。调用已经开始时，已发生的副作用可能保留。
- 继承会话中的取消证据会保留其所属轮次和调用身份。模型为报告提交证据时，可以分别引用每一次取消。
- JavaScript 和 Python 分析器启用了新的输入标识 `v4-dsh022rc1.1`。进行中的语义分析请用创建它的版本完成，或用 0.8.0 新建任务。既有分析结果和历史 V4 会话日志仍可读取，CLI 会在需要时重建旧的确定性缓存。

### 安装与验收

Web 可运行 `dsh plugin --profile web add dsh-session-insights@0.8.0` 安装，也可将 `web` 换成实际使用的配置。单独安装的 Python CLI 或 Skill 请通过各自的管理入口升级。

GitHub Actions 已在 Linux、macOS 和 Windows 上检查候选版本，包括 rc.1 官方会话与执行器契约。macOS 和 Windows 均在隔离配置中安装并核验了同一份包。两套系统都用真实模型完成了合成会话的语义报告，并从官方 Desktop 窗口运行了确定性报告命令。 [CI 运行](https://github.com/GreenLv/dsh-session-insights/actions/runs/42379286996)

npm 发布的压缩包包含 29 个文件。源码提交为 `ae4ecb39e8a609a90bf1ead03e288e9a5fa1de45`，压缩包的 SHA-256 为 `92cfbc43570c055c211e0e6d2a9a33775aedb4e88a92e893a48938f165eed625`。

### 已知上游依赖缺口
