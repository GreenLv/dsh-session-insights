# DSH Session Insights 0.4.0

## 中文

原生 Bundle 现在直接用 Node.js 生成复盘报告，无需再安装 Python。

### 变化

- 移除原生 Python 子进程及其环境变量、模块搜索路径继承。
- 收紧报告目录和文件访问，拒绝符号链接、硬链接及越界路径；模型输出通过校验后才写入。
- 新增运行产物清理工具，先预览再确认删除。不再写入跨运行共享语义缓存。
- 修复工具明确失败时，被输出中的“成功”文字覆盖的问题。

### 升级

需要 Node.js 20+（或 DSH 要求的更高版本），DSH 依赖仍为 `0.1.5-rc.2`。旧 Python 运行记录请通过原 CLI 完成，或重新生成报告。可选 Python CLI 继续保留。

65 项 Python 测试、42 项 Node 测试及 macOS、Linux、Windows CI 已通过，打包后检查覆盖中英文报告。真实 DSH 宿主和模型往返验收待完成。

[完整更新日志](https://github.com/GreenLv/dsh-session-insights/blob/v0.4.0/CHANGELOG.zh-CN.md) · [安装与使用](https://github.com/GreenLv/dsh-session-insights/blob/v0.4.0/README.zh-CN.md)

## English

The native Bundle now generates session reports directly in Node.js, without a Python installation.

### Changes

- Remove native Python subprocesses and inherited environment and module search paths.
- Restrict report storage, reject symlinks, hard links and escaping paths, and validate model output before writing it.
- Add run cleanup with a preview and explicit confirmation. Native runs no longer write a shared semantic cache.
- Preserve explicit tool failures when output text contains success-looking messages.

### Upgrade

Node.js 20+ is required, or the higher version required by DSH. The exact DSH dependency remains `0.1.5-rc.2`. Finish legacy Python runs through the CLI or generate a new report. The optional Python CLI remains available.

All 65 Python tests, 42 Node tests and macOS, Linux and Windows CI checks passed. Packaged-report checks cover both languages. Real DSH host and model round-trip acceptance remains pending.
