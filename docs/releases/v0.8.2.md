# DSH Session Insights 0.8.2

## English

Version 0.8.2 supports DeepSeek Harness (DSH) `0.2.2-rc.3` and verifies that conversations imported by its experimental DeepSeek chat importer retain their existing analysis meaning. This is a compatibility and correctness patch.

DSH `>=0.2.2-rc.3` is required; upgrade an older host before installing. rc.2 and earlier hosts are refused. The declared range admits later versions, while rc.3 is the exact acceptance target for this release. Node.js `>=24.9.0`, Cordis `~4.1.0` and Python `>=3.11` remain unchanged.

### Changes and upgrade

- Imported conversations preserve their source label, completed and failed turns, web-search/fetch results and attachment references. Missing usage remains unavailable; imported history is not counted as a new local model request. Regression coverage uses synthetic exports and the official importer and persistence path.
- Finish an in-progress semantic analysis with the version that created it, or start a new one after upgrading. The analyzer identity changes to `v4-dsh022rc3.1`; older deterministic caches are rebuilt as needed. Existing reports and source logs remain available.
- Acceptance tools check both target and non-target source-log directories around the actual report operation, including failure paths. Platforms and publication consume one frozen tarball whose producer, inputs and bytes are independently checked.

For Web, run `dsh plugin --profile web add dsh-session-insights@0.8.2`. Use the official Desktop application's plugin controls for Desktop. Separately installed Python CLI and Skill copies use their own managed installer.

### Known host risk

Plugin production/full, slim runtime and Python dependency scans are clean for the reviewed inputs. The full rc.3 host retains ten known dependency advisories, including four high-severity advisories. The maintainer accepted those findings for 0.8.2 and the exact reviewed rc.3 inputs on 2026-11-14. The raw host scan retains exit code 1 and is assessed as accepted known risk; this does not fix the vulnerabilities or cover changed inputs, new findings or scanner failures. See the [security policy](https://github.com/GreenLv/dsh-session-insights/blob/v0.8.2/SECURITY.md#known-upstream-dependency-gap).

## 简体中文

0.8.2 适配 DeepSeek Harness（DSH）`0.2.2-rc.3`，并验证其实验性 DeepSeek 会话导入器生成的会话保留既有分析语义。本次是兼容适配和正确性补丁。

最低要求为 DSH `>=0.2.2-rc.3`；旧宿主请先升级，rc.2 及更早宿主会被拒绝。声明范围允许后续版本准入，本次精确验收目标为 rc.3。Node.js `>=24.9.0`、Cordis `~4.1.0`、Python `>=3.11` 不变。

### 变化与升级

- 导入会话保留来源标签、完成与失败轮次、网页搜索/抓取结果和附件引用。缺失用量保持未知，导入历史不计为新发起的本地模型请求。回归使用合成导出和官方导入、持久化路径。
- 进行中的语义分析请用创建它的版本完成，或在升级后重新开始。分析身份更新为 `v4-dsh022rc3.1`，旧确定性缓存按需重建；既有报告和源日志仍可使用。
- 验收工具在实际报告操作前后检查目标及非目标源日志目录，覆盖失败路径。各平台与公开发布消费同一份冻结归档，分别校验生产工具、输入和包字节。

Web 可运行 `dsh plugin --profile web add dsh-session-insights@0.8.2`；Desktop 使用官方应用内的插件管理入口。单独安装的 Python CLI 与 Skill 通过各自的管理安装器更新。

### 已知宿主风险

插件生产/完整依赖、精简运行时和 Python 依赖扫描在已审输入范围内为 clean。rc.3 完整宿主仍有十项已知依赖公告，其中四项高危。维护者于 2026-11-14 接受了 0.8.2 精确 rc.3 输入中的这些发现。宿主原始扫描保留退出码 1，单独评估为已接受的已知风险；这不修复漏洞，也不覆盖输入变化、新发现或扫描故障。详见[安全说明](https://github.com/GreenLv/dsh-session-insights/blob/v0.8.2/SECURITY.md#known-upstream-dependency-gap)。
