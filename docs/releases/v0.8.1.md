# DSH Session Insights 0.8.1

## English

Reports now distinguish a rejected approval from a cancelled approval window or an unavailable approval channel. Repeated non-grants retain separate evidence even when their summaries match.

Version 0.8.1 requires DeepSeek Harness (DSH) `>=0.2.2-rc.2`. Upgrade an older host before installing. The declared range admits later versions, while `0.2.2-rc.2` is the exact host tested for this release. Node.js `>=24.9.0` and Cordis `~4.1.0` remain required.

### Changes and upgrade

- A cancelled approval window and an unavailable approval channel have separate counts and evidence; they are not counted as caller cancellations or tool execution failures. An actual approval rejection remains a permission-boundary event.
- Team-mode changes are recorded as configuration context, without adding user tasks or completion claims.
- Finish an in-progress model analysis with the version that created it, or start a new analysis after upgrading. Existing reports and source logs remain available; old deterministic caches are rebuilt when needed.

Install the Web version with `dsh plugin --profile web add dsh-session-insights@0.8.1`, or use the official Desktop application's plugin controls. Update a separately installed Python CLI or Skill through its own installer.

### Verification and known host risk

All 14 [CI jobs](https://github.com/GreenLv/dsh-session-insights/actions/runs/43269665320) passed on Linux, macOS and Windows. The same package was installed in isolated Web and Headless profiles on macOS and Windows; both systems produced populated reports and used a live model to analyze synthetic sessions. Both official Desktop applications executed the report command, and their generated reports were checked in a browser.

The tarball contains 29 files, is 211,369 bytes, and has SHA-256 `5f974b37e28cef4a955e80729d9b94254273b2e66a19880c2f568ef6129e0db2`.

DSH rc.2 replaces the earlier vulnerable Zod pins, but its full official host still has ten dependency advisories: eight for undici, including four high-severity advisories, and one each for the MCP client and fflate. The maintainer accepted those known findings for 0.8.1 and the reviewed exact rc.2 host inputs. Plugin production/full, slim runtime and Python dependency scans were clean; the host scan retained exit code 1 and was assessed as accepted known risk. The decision does not fix the vulnerabilities or cover changed inputs or new findings. See the [security policy](https://github.com/GreenLv/dsh-session-insights/blob/811d1456f9154a4a71e70f6ab9e98e5b3548e0ca/SECURITY.md#known-upstream-dependency-gap).

## 简体中文

报告现在分别记录审批拒绝、审批窗口取消和审批通道不可用。多次未放行即使摘要相同，也会各自保留证据。

0.8.1 要求 DeepSeek Harness（DSH）`>=0.2.2-rc.2`。旧宿主请先升级，再安装插件。声明的版本范围允许后续版本准入；本次精确测试的宿主是 `0.2.2-rc.2`。Node.js `>=24.9.0` 和 Cordis `~4.1.0` 的要求不变。

### 变化与升级

- 审批窗口取消和审批通道不可用分别计数并保留证据，不计为调用者取消或工具执行失败。实际审批拒绝仍计入权限边界。
- 团队模式切换记录为配置上下文，不增加用户任务或完成记录。
- 进行中的模型分析请用创建它的版本完成，或在升级后重新开始。既有报告和源日志仍可读取，旧的确定性缓存按需重建。

Web 版可运行 `dsh plugin --profile web add dsh-session-insights@0.8.1`，官方桌面版可使用应用内的插件管理入口。单独安装的 Python 命令行工具或 Skill 请通过各自的安装脚本升级。

### 验证与已知宿主风险

Linux、macOS 和 Windows 上的 14 项 [CI 检查](https://github.com/GreenLv/dsh-session-insights/actions/runs/43269665320)均已通过。macOS 和 Windows 已在隔离的 Web、Headless 配置中安装同一份包，生成非空报告，并使用合成会话完成真实模型分析。两端官方 Desktop 均成功执行报告命令，生成的报告也已在浏览器中验证。

压缩包包含 29 个文件，大小为 211,369 字节，SHA-256 为 `5f974b37e28cef4a955e80729d9b94254273b2e66a19880c2f568ef6129e0db2`。

DSH rc.2 替换了此前有漏洞的 Zod 精确依赖，但官方完整宿主仍有十项依赖公告：undici 八项，其中四项为高危；MCP client 和 fflate 各一项。维护者接受了 0.8.1 在已审查精确 rc.2 宿主输入范围内的这些已知风险。插件生产/完整依赖、精简运行时和 Python 依赖扫描未发现已知漏洞；宿主扫描保留退出码 1，并单独评估为已接受的已知风险。这一决定不修复漏洞，也不涵盖输入变化或新发现。详见[安全说明](https://github.com/GreenLv/dsh-session-insights/blob/811d1456f9154a4a71e70f6ab9e98e5b3548e0ca/SECURITY.md#known-upstream-dependency-gap)。
