# DSH Session Insights 0.8.1（候选，未发布）

## English

0.8.1 supports DeepSeek Harness (DSH) `0.2.2-rc.2` and later. Upgrade older hosts before installing. Node.js `>=24.9.0` and Cordis `~4.1.0` are unchanged.

### Changes and upgrade

- Reports distinguish a rejected approval from a cancelled approval window or an unavailable approval channel. Repeated non-grants keep their own evidence, even when their summaries match. They do not become caller cancellations or successful executions.
- Team-mode changes are recorded as configuration context, without adding user tasks or completion claims.
- Start a new semantic analysis after upgrading, or finish an existing run with the version that created it. Old deterministic caches rebuild when needed; existing runs, reports and source logs remain available.
- Dependency-audit summaries preserve capture failures and verify the actual host identity before executor acceptance.

### Verification and known host risk

Source and official rc.2 catalog/service/executor checks have run on the macOS development host. Exact-commit CI, frozen-artifact macOS/Windows acceptance, official Desktop interaction and real-model checks remain pending; the [candidate record](../acceptance/v0.8.1-candidate.md) separates those stages.

DSH rc.2 fixes the old Zod pins. The full official host still has ten dependency advisories. On 2026-11-13 the maintainer accepted the exact 0.8.1 host inputs and reviewed findings; raw failed scans remain distinct from clean plugin/runtime scopes. This decision does not fix the host vulnerabilities or cover changed inputs and new findings. See the [security policy](../../SECURITY.md#known-upstream-dependency-gap).

After release, install Web with `dsh plugin --profile web add dsh-session-insights@0.8.1`, or use the official Desktop plugin controls. Update a standalone Python CLI or Skill separately. [Full changelog](../../CHANGELOG.md#081---unreleased-candidate)

## 简体中文

0.8.1 支持 DeepSeek Harness（DSH）`0.2.2-rc.2` 及更高版本。旧宿主请先升级，再安装插件；Node.js `>=24.9.0`、Cordis `~4.1.0` 的要求不变。

### 变化与升级

- 报告分别记录审批拒绝、审批窗口取消和审批通道不可用。多次未放行即使摘要相同，也各自保留证据，不会被当成调用者取消或成功执行。
- 团队模式切换只计为配置上下文，不增加用户任务或完成记录。
- 升级后请新建语义分析，或用原版本完成已有运行。旧确定性缓存按需重建，既有运行、报告和源日志均保留。
- 依赖审计汇总不会覆盖采集阶段的失败；执行器验收会核对实际宿主身份。

### 验证与已知宿主风险

macOS 开发主机已运行源码及官方 rc.2 目录、服务和执行器检查。精确提交 CI、冻结制品的 macOS/Windows 验收、官方桌面交互与真实模型检查仍待完成；[候选验收记录](../acceptance/v0.8.1-candidate.md)分别记录这些阶段。

DSH rc.2 已修复旧 Zod 精确依赖，但官方完整宿主仍有十项依赖公告。维护者于 2026-11-13 接受了本次 0.8.1 精确宿主输入和已审查发现范围内的风险，原始失败扫描与插件/精简运行时的干净范围分别保留。这一决定不修复宿主漏洞，也不涵盖输入变化或新发现。详见[安全说明](../../SECURITY.md#known-upstream-dependency-gap)。

发布后，Web 版可运行 `dsh plugin --profile web add dsh-session-insights@0.8.1`，官方桌面版可使用插件管理入口；单独安装的 Python CLI 或 Skill 请分别升级。[完整变更记录](../../CHANGELOG.zh-CN.md#081---未发布候选)
