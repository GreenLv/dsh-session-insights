# v0.3.1 - DSH 0.1.5 session compatibility

## English

Upgraded DSH sessions now appear in reports. The reader selects one current log generation per session, supports compressed and plaintext generations 0–3, and reports unreadable or unsupported generations without falling back to stale history.

Human-work counts exclude injected context. System messages and unsuccessful model attempts are tracked separately; replaced conversation text leaves semantic evidence, while historical tool and token statistics remain. The bridge also uses the same caller-supplied time window for both report modes.

The minimum DSH declaration remains `0.1.0-rc.8`. This update targets `0.1.5-rc.2`, with macOS native workflow verification and the repository's three-platform CI. Windows/Linux full native model workflows are not repeated for this shared-parser change; future DSH versions are not claimed as verified. Upgrade the Bundle through your existing DSH installation flow and restart your host manually when required.

[English changelog](https://github.com/GreenLv/dsh-session-insights/blob/v0.3.1/CHANGELOG.md)

## 简体中文

升级 DSH 后的新会话现在能够进入报告。读取器为每个会话只选择一个当前日志代际，支持第 0–3 代压缩与明文日志；无法读取或版本不支持时明确报告，不退回过时日志。

用户工作统计排除系统注入内容，系统消息和未形成回复的模型尝试单独统计。被替换的对话不再进入语义证据，历史工具与 Token 统计仍保留；两种报告模式也使用相同的调用方时间窗口。

最低 DSH 版本声明仍为 `0.1.0-rc.8`。本次针对 `0.1.5-rc.2` 完成 macOS 原生流程验证，并运行仓库现有三平台 CI。此次共用解析器修复不重复 Windows/Linux 完整原生模型流程，也不声称未来 DSH 版本已验证。沿用现有 DSH 安装流程升级 Bundle，需要时手动重启宿主。
