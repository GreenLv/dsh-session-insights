# v0.3.2 - DSH market compatibility metadata

## English

The npm package now declares DSH `0.1.5-rc.2` consistently in every field used by DSH plugin markets and installers. Market cards will therefore stop advertising the retired `0.1.0-rc.8` threshold after their catalog refresh.

This release changes compatibility metadata only. Runtime behavior is unchanged from `0.3.1`, whose source, CI, and macOS native workflow evidence remains applicable. The `0.3.2` package, installation, registry, GitHub Release, and market display will be verified as separate publication surfaces.

[English changelog](https://github.com/GreenLv/dsh-session-insights/blob/v0.3.2/CHANGELOG.md)

## 简体中文

npm 软件包现在会在 DSH 插件市场和安装器读取的全部字段中统一声明 DSH `0.1.5-rc.2`。市场目录刷新后，卡片将不再显示已经停止支持的 `0.1.0-rc.8` 门槛。

本次仅修改兼容元数据，运行时行为与 `0.3.1` 相同；该版本的源码、CI 和 macOS 原生流程证据仍然适用。`0.3.2` 软件包、安装、registry、GitHub Release 和市场显示将作为不同发布面分别验证。
